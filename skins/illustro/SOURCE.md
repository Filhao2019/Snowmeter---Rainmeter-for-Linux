# Source of this folder

This folder is an upstream Rainmeter skin bundled with Snowmeter. It is not covered by Snowmeter's MIT license; it keeps its own license.

- Skin: illustro
- Author: Rainmeter team (Kaelri, Poiru, jsmorley et al.)
- Upstream: https://github.com/rainmeter/rainmeter
- Exact ref: 6b2950c239dd5b0bd7e1792ab2496b3434ba90f6 (path Build/Skins/illustro)
- License: GPL-2.0 (see LICENSE in this folder)
- Files removed from the upstream copy: none. Removed executables and DLLs only run on Windows; they are not needed on Linux.
- Everything else is byte-for-byte upstream; this SOURCE.md (and LICENSE where upstream has no file) were added.

- `Google/Google.ini` is taken from the stock release tag `v4.5.27.3934` instead of the development branch: the development version uses the TextEdit meter, which only exists in Rainmeter 5.0 builds; the 4.5 version uses the InputText plugin, which Snowmeter supports.
